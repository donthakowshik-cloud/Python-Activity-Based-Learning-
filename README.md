## About the Project

This repository contains 10 Python programming case studies designed to demonstrate computational thinking, algorithm development, pseudocode, flowcharts, and fundamental Python programming concepts.

Each program solves a practical, real-world problem using concepts from the prescribed Python programming syllabus.

## Programs Included

### 91. Advanced String-Based Registration Record Analyzer
Parses registration records, validates field lengths and formats, extracts information, detects duplicate registration IDs, and classifies errors.

**Concepts:** Strings, lists, loops, conditional statements, validation.

### 92. Multi-Event Sports Scheduling and Scoring
Manages sports fixtures, identifies scheduling conflicts, calculates team points, and generates final rankings.

**Concepts:** Lists, tuples, nested loops, conditional statements, tuple unpacking.

### 93. Smart Public Transport Fare Reconciliation
Calculates passenger fares for different routes and passenger categories, compares expected and collected revenue, and identifies discrepancies.

**Concepts:** Variables, arithmetic operators, lists, loops, conditional statements.

### 94. Disaster Relief Supply Allocation
Compares available supplies with area-wise demand, prioritizes urgent requirements, allocates limited resources, and calculates unmet demand.

**Concepts:** Nested lists, loops, conditions, arithmetic operations.

### 95. Integrated Manufacturing Production Planner
Analyzes raw material availability, production demand, defects, and order feasibility to identify shortages and quality violations.

**Concepts:** Variables, operators, lists, tuples, conditional statements.

### 96. Multi-Criteria Library Resource Distribution
Allocates available book copies to library branches according to priority rules and calculates unmet demand.

**Concepts:** Nested lists, loops, conditions, resource allocation.

### 97. Smart Campus Incident and Maintenance Prioritization
Evaluates maintenance reports based on severity, location, and frequency, ranks incidents, and identifies urgent cases.

**Concepts:** Tuples, lists, loops, conditions, ranking logic.

### 98. University Academic Progression Audit
Checks semester marks, attendance, subject pass conditions, and prerequisite completion to determine academic progression eligibility.

**Concepts:** Nested lists, tuples, loops, conditional statements, logical operators.

### 99. Integrated E-Commerce Order Processing and Reconciliation
Processes product orders, discounts, dispatches, returns, and inventory updates while calculating revenue and identifying discrepancies.

**Concepts:** Lists, tuples, arithmetic operators, loops, inventory management.

### 100. Comprehensive Smart Campus Management Simulation
Implements a menu-driven campus management system for student records, attendance, marks, event registration, resource allocation, and summary reporting.

**Concepts:** Strings, lists, nested lists, tuples, tuple unpacking, loops, conditional statements.

## How to Run

1. Install Python 3 on your computer.
2. Clone or download this repository.
3. Open a terminal in the project folder.
4. Run any program using:

```bash
python program91.py
```

Replace `program91.py` with the filename of the program you want to execute. Program 100 is menu-driven and accepts user input.
